### 环境的配置

创建独立运行的python虚拟环境

    conda create -n study_RL python=3.11

    pip3 install gym -i https://pypi.tuna.tsinghua.edu.cn/simple

    pip3 install gymnasium -i https://pypi.tuna.tsinghua.edu.cn/simple

    pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cu126
